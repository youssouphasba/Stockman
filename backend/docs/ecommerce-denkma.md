# Livraison des commandes en ligne avec Denkma

Denkma livre au Sénégal à partir de positions GPS et de points relais, pas d'adresses écrites. Stockman s'appuie sur Denkma Pro pour que le client choisisse le lieu de livraison sur une carte et que le commerçant expédie en un geste.

## Créer ou connecter son compte Denkma Pro

La carte « Livraison Denkma » se trouve dans Paramètres > Site e-commerce (sur mobile Starter, dans la rubrique Boutique en ligne).

**Pas encore de compte Denkma Pro** : « Créer mon compte Denkma Pro » ouvre un formulaire dans l'application mobile Stockman :

1. le commerce : commerçant ou entreprise, nom du commerce, nom du responsable et numéro de téléphone (Sénégal ou France) ;
2. le point de collecte : le commerçant se place à l'endroit où le livreur récupérera les colis et touche « Utiliser ma position actuelle » ; la précision doit être de 60 m au plus (sinon, se placer à l'extérieur ou près d'une fenêtre et relocaliser). Il décrit le lieu (rue, repère), le quartier et la ville ;
3. un code PIN Denkma de 4 à 12 chiffres, saisi deux fois : avec son numéro, il permet de se connecter à l'application Denkma pour recharger le compte transport et suivre les colis ;
4. l'acceptation des conditions et de la politique de confidentialité de Denkma ;
5. « Recevoir le code par SMS », puis la saisie du code à 6 chiffres et « Créer mon compte Denkma Pro ».

Le compte est créé chez Denkma et relié aussitôt à la boutique. Il reste « en attente de validation » : Denkma vérifie le commerce, puis ouvre les livraisons. En attendant, la carte l'indique et les clients écrivent leur adresse comme avant. Une fois le compte validé, il faut recharger le compte transport dans l'application Denkma pour que les modes de livraison soient proposés (voir ci-dessous). Sur le web, la carte invite à créer le compte depuis l'application mobile, qui localise le point de collecte et reçoit le SMS.

**Déjà un compte Denkma Pro** : « J'ai déjà un compte Denkma Pro » (ou « Connecter Denkma Pro ») ouvre Denkma Pro ; le commerçant y autorise Stockman, puis revient dans Stockman : la connexion est faite. Il faut un compte Denkma Pro approuvé, avec le point de collecte confirmé et le compte transport rechargé. Si le numéro saisi dans le formulaire de création a déjà un compte Denkma, Stockman le signale : il faut alors connecter ce compte existant.

## Gérer ses livraisons dans l'application Denkma

Après la création du compte, le commerçant installe l'application Denkma (Google Play ou App Store) et s'y connecte avec le numéro et le code PIN choisis dans Stockman ; il arrive dans son espace Pro. Il peut aussi utiliser Denkma Pro sur le web (https://api.denkma.com/pro/), avec les mêmes identifiants. Une fois Denkma relié, la carte « Livraison Denkma » affiche « Gérez vos livraisons dans l'application Denkma », avec « Télécharger l'application Denkma » (la boutique du téléphone) et « Ou ouvrir Denkma Pro sur le web » ; sur le web, les liens Google Play, App Store et Denkma Pro sur le web.

Le partage des rôles :

- dans Denkma : recharger le compte transport (sans solde, aucun mode de livraison n'est proposé aux clients et aucune expédition ne part), suivre les colis ;
- dans Stockman : recevoir les commandes, lancer chaque expédition avec « Livrer avec Denkma » et voir le suivi dans la commande.

La carte permet aussi d'indiquer le colis habituel (petit ou gros colis, poids en kilos), qui sert au calcul du prix, et de déconnecter Denkma. Tous les abonnements la gèrent depuis l'application mobile ; sur le web, la gestion est réservée à Enterprise.

## Ce que voit le client

Quand Denkma est connecté, le panier ne demande plus d'adresse. Le client choisit :

- « À domicile » : il indique sa position exacte sur la carte Denkma (ou avec la localisation de son téléphone) ;
- « En point relais » : il choisit un point relais Denkma proche de chez lui.

Sur l'adresse Stockman du site, la carte s'affiche dans la boutique ; sur un domaine connecté, elle s'ouvre dans un nouvel onglet et la boutique détecte seule la confirmation. Le prix exact de la livraison s'affiche ensuite et s'ajoute au total. Le téléphone devient obligatoire, pour le livreur, au format sénégalais (ou français). Un mode n'est proposé que si le commerçant peut financer le transport. La livraison se règle avec la commande : Denkma ne collecte pas le paiement des marchandises.

## Livrer avec Denkma

Dans le détail d'une commande où le client a choisi Denkma, le bloc « Livraison Denkma » indique la destination, l'état de l'expédition et le numéro de suivi. « Livrer avec Denkma » demande :

1. de confirmer que le client a payé le montant dû (articles et livraison) ;
2. une photo du colis prêt, exigée par Denkma pour la sécurité de l'envoi.

Stockman confirme alors le paiement à Denkma, réserve le transport sur le compte Denkma Pro au prix vu par le client (ou à un nouveau prix s'il a expiré), envoie la photo, déclare le colis prêt et demande l'enlèvement. Le livreur vient au point de collecte enregistré dans Denkma Pro. « Actualiser le suivi » relit l'état chez Denkma ; les événements de Denkma le mettent aussi à jour tout seuls. Quand Denkma remet le colis, la commande passe à « livrée » et devient une vente ; si ce passage automatique échoue (stock insuffisant, par exemple), le commerçant est prévenu et valide la livraison lui-même. Annuler ou refuser la commande annule aussi sa livraison Denkma si elle n'est pas encore partie.

## Messages fréquents

- « Solde transport Denkma insuffisant » : rechargez le compte transport dans l'application Denkma (ou Denkma Pro sur le web) ; l'expédition pourra ensuite partir.
- « La position du client ou le point relais n'est pas confirmé chez Denkma » : le choix du client n'a pas pu être enregistré à temps ; contactez-le, puis créez la livraison dans Denkma Pro.
- « La connexion à Denkma n'est plus valable » : reconnectez Denkma dans Paramètres > Site e-commerce.
- « Compte Denkma Pro en attente de validation » : Denkma vérifie le commerce ; la livraison Denkma s'ouvrira dans la boutique dès la validation.
- « Ce numéro a déjà un compte Denkma » : utilisez « J'ai déjà un compte Denkma Pro » pour connecter ce compte, ou un autre numéro.
- « La vérification du numéro ne correspond pas ou a expiré » : recommencez l'envoi du SMS ; le code est valable quelques minutes.
- « Position trop imprécise » : placez-vous à l'extérieur ou près d'une fenêtre, puis relocalisez-vous.
- Les commandes passées sans livraison Denkma (adresse écrite) ne proposent pas « Livrer avec Denkma ».
